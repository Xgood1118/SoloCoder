# Angular 工作流引擎

一个基于 Angular 17 的审批流程工作流引擎，支持流程设计、发起、审批和状态追踪。

## 功能特性

### 1. 流程定义
- 创建和编辑审批流程模板
- 支持多种节点类型：开始节点、审批节点、条件节点、结束节点
- 审批节点支持配置审批人、审批规则（单人/或签/会签）
- 节点顺序可通过上下箭头调整
- 支持条件分支（如金额大于5万需要额外审批）
- 表单字段自定义（文本、数字、日期、多行文本）

### 2. 发起流程
- 从已定义的模板发起流程实例
- 填写表单数据
- 支持保存草稿功能
- 流程预览

### 3. 审批操作
- 待办列表查看需要审批的流程
- 支持单个审批、批量审批
- 支持通过、驳回、转交操作
- 驳回可选择退回修改或直接终止
- 被驳回的流程支持修改后重新提交

### 4. 流程状态
- 可视化进度条显示当前节点
- 完整的审批历史记录
- 各节点审批详情查看
- 支持查看每个节点的审批意见

### 5. 模板管理
- 模板复制
- JSON 格式导入/导出
- 多用户切换演示

## 安装和运行

### 前置条件
- Node.js 18+
- npm

### 安装依赖

```bash
npm install
```

### 启动开发服务器

```bash
npm start
```

访问 http://localhost:4200 查看应用

### 构建生产版本

```bash
npm run build
```

## 数据存储

应用使用 localStorage 存储数据，包括：
- 流程模板
- 流程实例
- 用户信息
- 当前登录用户

## 演示数据

首次运行会自动创建演示数据：
- 5 个用户（张三、李四、王五、赵六、钱七）
- 3 个流程模板（请假审批、报销审批、采购审批）
- 4 个流程实例（草稿、审批中、已完成、已驳回）

## 使用说明

### 1. 设计流程模板
1. 点击"模板管理"进入模板列表
2. 点击"+ 新建模板"创建新模板
3. 在模板设计器中添加审批节点和条件节点
4. 配置每个节点的审批人和审批规则
5. 设置表单字段
6. 保存模板

### 2. 发起流程
1. 在模板列表点击"发起"按钮
2. 填写表单数据
3. 可保存草稿或直接提交

### 3. 审批流程
1. 使用右上角的用户切换，切换到审批人账号
2. 在"待办审批"中查看待办事项
3. 点击"审批"进入审批详情
4. 选择通过、驳回或转交

### 4. 查看流程状态
1. 在"我的流程"中查看发起的流程
2. 点击"查看"查看详细信息
3. 查看进度条和审批历史

### 5. 重新提交驳回的流程
1. 在"我的流程"中找到被驳回的流程
2. 点击"修改重提"
3. 修改表单数据后重新提交

## 审批规则说明

- **单人审批**：指定一个审批人，该人通过即可
- **或签**：多个审批人，任意一人通过即可
- **会签**：多个审批人，需要所有人都通过
