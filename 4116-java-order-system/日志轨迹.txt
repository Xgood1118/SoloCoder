### 边界条件处理

| 边界 | 处理方式 |
|------|---------|
| 重复下单 | Redis SETNX 幂等键 `userId:bizType:timestamp`，5分钟窗口 |
| 库存并发扣减 | Redis Lua 原子操作 + DB 乐观锁版本号 + `@DistributedLockAnnotation` |
| 支付回调乱序 | 检查订单当前状态 + `callbackNo` 去重 + 主动轮询查证 |
| 重复支付 | `checkDuplicatePayment()` 检测后自动触发退款 |
| 金额精度 | `BigDecimal` + `HALF_UP` 舍入，统一2位小数 |
| 分布式事务 | Saga 模式：每步失败可补偿（库存回滚、积分回滚、优惠券回滚） |
