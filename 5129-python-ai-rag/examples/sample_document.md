# RAG 系统技术文档

## 概述

检索增强生成（Retrieval-Augmented Generation，RAG）是一种结合了信息检索和文本生成的 AI 技术框架。它通过从外部知识库中检索相关文档片段，然后将这些片段作为上下文提供给大语言模型，从而生成更准确、更相关的回答。

## 核心功能

### 1. 文档解析

RAG 系统支持多种文档格式的解析：
- PDF 文档：支持横排和竖排文字、表格、图表标题提取
- Word 文档（.docx, .doc）：保留文档结构和格式
- 纯文本文件（.txt）：支持多种编码自动检测
- Markdown 文件（.md, .markdown）：解析标题、表格、代码块等元素

### 2. 文本分块策略

分块策略是 RAG 系统的关键环节：
- **可配置大小**：默认 512 tokens，可根据需求调整
- **句子边界保护**：避免在句子中间切分，保持语义完整性
- **重叠机制**：相邻块之间有 50 tokens 的重叠，确保上下文连贯
- **表格特殊处理**：表格按行分组，表头重复出现在每个分块中

### 3. Embedding 生成

系统支持两种 Embedding 方案：
- **OpenAI Embedding**：使用 text-embedding-ada-002 模型，维度 1536
- **本地 Embedding**：使用 sentence-transformers，支持本地部署的模型

### 4. 向量存储

支持两种向量数据库后端：
- **Chroma**：轻量级本地向量数据库，适合开发和小规模部署
- **Milvus**：高性能分布式向量数据库，适合生产环境大规模部署

### 5. 重排序机制

使用 cross-encoder 模型进行两阶段检索：
1. **粗排**：向量检索召回 Top 50 结果
2. **精排**：cross-encoder 精细排序后返回 Top 5 结果

### 6. 多文件协调

各模块通过中间文件传递数据：
```
原始文档 → 解析 JSON → 分块 JSON → 向量文件 → 向量数据库
```

每个步骤可以独立运行，也可以串联执行。

## 技术架构

```
┌─────────────┐    ┌────────────┐    ┌───────────┐    ┌────────────┐
│ 文档解析器  │ →  │ 文本分块器 │ →  │ Embedding │ →  │ 向量存储   │
└─────────────┘    └────────────┘    └───────────┘    └────────────┘
                                                          ↓
┌─────────────┐    ┌────────────┐    ┌───────────┐    ┌────────────┐
│  结果缓存   │ ←  │  重排序器  │ ←  │  检索器   │ ←  │   查询     │
└─────────────┘    └────────────┘    └───────────┘    └────────────┘
```

## 性能指标

| 指标 | 数值 | 说明 |
|------|------|------|
| 解析速度 | ~50 页/秒 | PDF 文档 |
| 分块速度 | ~1000 块/秒 | 512 tokens/块 |
| Embedding 速度 | ~100 块/秒 | OpenAI API |
| 检索延迟 | <100ms | Top 50 召回 |
| 重排序延迟 | ~50ms | Top 5 精排 |
