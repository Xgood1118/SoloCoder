#  Python 预算追踪器

这次要做的是一个个人和小型团队的预算追踪工具，Python 实现，主要帮助用户记录和分析收入支出情况。说实话记账这件事很多人都有需求，但是现有的记账软件要么太复杂功能堆砌界面看着头晕，要么太简单分析能力几乎没有，而且数据都在人家服务器上，有些人对隐私比较在意不愿意把财务数据放到云端，担心数据被分析或者泄露。所以我们做一个本地优先的方案，用户的数据存在自己电脑上，用起来也灵活，不用担心数据安全，同时也不排斥将来可以同步到云端。

记账功能要支持多账户，比如现金账户、银行账户、信用卡账户、支付宝账户、微信账户等等，每个账户有独立的余额和交易明细，账户之间可以转账。交易记录要包含金额、类别、时间、备注、标签这些字段，金额要分正负收入为正支出为负，类别要能自定义比如餐饮、交通、购物、娱乐、医疗、教育这些常用类别，用户要能新增修改删除类别，也要有默认的收支类型区分收入和支出要分开。转账也要支持，就是从一个账户转到另一个账户，这种内部转账不应该算收入或者支出只改变账户余额。批量导入要支持，CSV 文件要能导入，有些银行可以导出交易明细，导入进来要能智能识别类别比如根据商户名称或者备注关键词来自动分类。

预算管理要做，用户可以给每个类别设置月度预算或者年度预算，比如这个月餐饮预算两千五、花呗预算三千五，预算可以按月份滚动也可以按年度累计。系统要能自动追踪已花费的金额，占预算的百分比要能随时看到，要能展示各分类的预算使用进度。预算快用完或者超支的时候要有提醒，这个提醒阈值要可配置比如预算用了百分之八十就提醒一次、超过百分之百再提醒一次，可以用桌面通知或者邮件通知。历史预算执行情况要能对比看，比如这个月和上个月相比在哪些类别上超支了，趋势图要能展示。预算调整要记录，每次修改预算都要记下来什么时候改过，从多少改到多少，方便审计。

数据可视化要做得好，趋势图要能展示每月支出走势用折线图，饼图要能展示各类别占比方便知道钱都花哪儿了，条形图要能对比不同月份同一类别的支出情况比如对比最近三个月餐饮支出有没有超标。数据导出要支持，CSV 和 Excel 格式都要能导出，方便用户做进一步分析或者备份给财务。数据存储默认用 SQLite 本地文件，要简单可靠不用额外部署数据库，定期备份功能要有比如每天自动备份一次。命令行界面要做，习惯用命令行的用户可以直接敲命令来记账和查账比如 add expense 50 餐饮，或者 query this month。同时也要有简单的图形界面或者 Web 界面，方便不习惯命令行的用户使用，可以用 PyQt 或者做个轻量 Web 服务。

多币种支持要做，现在很多人有海外消费或者海淘需求，不同币种的消费要能正确转换算到统一货币来统计比如都换算成人民币，汇率可以用公开接口获取比如银行汇率或者 fixer.io 但是要缓存住不然每次查费时间。数据校验要做，账户余额要对得上，就是所有账户余额加起来要等于初始余额加收入减支出，类别金额加总要和总支出匹配，这个校验如果有差异要能提示用户去检查去找到漏记或者记错的条目。周期性账单管理要做，订阅服务比如会员费、房租、水电费这些定期支出要能自动生成提醒和记账模板。单元测试要覆盖记账、预算计算、报表生成这些核心功能。
