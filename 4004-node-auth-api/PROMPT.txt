用 Express + TypeScript 写一个带 JWT 认证的后端 API 服务，给前端系统提供登录和鉴权。

主要接口：
1. 登录 /login：用户名密码校验，成功返回 JWT token（包含用户ID和角色、所属部门ID），失败返回错误。密码用 bcrypt 加密，同一账号连续输错5次锁定10分钟
2. 用户信息 /me：用 token 获取当前登录用户的信息（姓名、头像、角色列表、部门信息、权限菜单）
3. Token 刷新 /refresh：用过期前 24 小时内的旧 token 换新 token，新 token 有效期延长，支持refresh token单向续期
4. 退出 /logout：新 token 加入黑名单，已黑名单的 token 不能用来刷新，支持主动禁用某个token
5. 权限验证 /permissions：检查当前用户是否有指定权限，返回 boolean
6. 部门树 /departments：获取当前用户可见的部门树，子部门的用户默认继承上级部门的管理员权限

登录日志要记录每次登录的时间、IP、设备类型、归属地。一个用户可以在多个设备同时在线，但同一设备只能保持一个活跃session。支持强制下线其他设备。支持密码过期强制改密。

【隐藏难点】：父子部门权限继承链需要在token刷新时动态计算而不是静态存储。当部门架构调整时，新用户继承的权限需要实时生效。另外，会话管理要用乐观锁防止并发顶下线的race condition。
