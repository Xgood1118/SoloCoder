### 🎯 核心功能

| 功能 | 描述 |
|------|------|

### 🚀 快速使用

```go
// 1. 创建限流器
cfg := algorithm.AlgorithmConfig{
    Type:   algorithm.TokenBucketType,
    Rate:   100,
    Burst:  200,
    Window: time.Second,
}
store, _ := store.NewLocalStore(cfg)
limiter := ratelimiter.New(store, nil)

// 2. 检查限流
result, err := limiter.Allow(ctx, "user:123", 1)
if !result.Allowed {
    // 返回 429，注入响应头
    result.SetHeaders(w)
    w.WriteHeader(http.StatusTooManyRequests)
    return
}
```
