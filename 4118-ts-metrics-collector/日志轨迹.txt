### ✅ 已实现的核心功能

**1. 指标定义与注册**
- 支持 Counter、Gauge、Histogram、Summary 四种类型
- 全局单例 Registry，防止重复注册
- 标签维度支持，高基数检测
- 工厂方法：`createCounter`、`createGauge`、`createHistogram`、`createSummary`

**2. 数据采集**
- HTTP 拉模式：`/metrics` 端点返回 Prometheus 格式
- 主动推模式：应用代码直接调用 API
- 可配置采集间隔，指数退避重试
- 独立超时控制，不影响其他目标

**3. 数据聚合与计算**
- 滑动窗口和固定时间窗口
- 聚合函数：Sum、Avg、Min、Max、Count、Percentile
- 多级聚合（分钟→小时）
- 内存压力保护，乱序数据处理

**4. 告警规则**
- 完整状态机：Normal → Pending → Firing → Acknowledged → Resolving → Recovered → Normal
- 支持 AND/OR 条件组合
- 阈值告警、速率变化告警
- 告警分级（P0-P3）、抑制、认领

**5. 数据存储**
- 可插拔存储后端（InfluxDB、Prometheus、ClickHouse、TimescaleDB）
- MemoryStorage 作为默认实现
- 批量写入、降采样、数据过期清理

**6. 可视化与 API**
- Grafana 兼容的 Prometheus 格式
- REST API：`/api/alerts`、`/api/metrics`、`/api/status`
- 面板导入导出支持
